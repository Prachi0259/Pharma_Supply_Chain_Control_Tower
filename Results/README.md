# Analysis Results

These CSVs contain the outputs used to build the project story and Power BI dashboard.

- `executive_kpis.csv` — portfolio-level service, inventory, supplier and expiry KPIs
- `drug_stockout_analysis.csv` — drug-level service gaps
- `regional_stockout_analysis.csv` — regional hotspots
- `drug_location_analysis.csv` — 125 drug-location combinations
- `supplier_performance.csv` — supplier quantity and delivery performance
- `inventory_vs_safety_stock.csv` — inventory positioning against safety stock
- `replenishment_by_drug_location.csv` — PO execution by drug and location
- `expiry_exposure.csv` — expiry quantity/value exposure
- `drug_abc_xyz.csv` — ABC-XYZ segmentation
- `reorder_point_scenario.csv` — baseline and 95% scenario ROP outputs
